### 🤖 YouTube RAG Chatbot

AI-powered chatbot that answers questions from YouTube video transcripts using **Retrieval-Augmented Generation (RAG)**.

- 🔹 Retrieves and processes YouTube transcripts
- 🔹 Splits transcripts into meaningful chunks
- 🔹 Generates embeddings and performs vector similarity search
- 🔹 Uses retrieved context to generate grounded answers
- 🔹 Built with **LangChain, Gemini, Chroma & Streamlit**
